## 1. Proximity / distance — what was audited

`harness/candidates.py`, `harness/baselines.py`, `harness/topology.py`,
`harness/objgeom.py`, `harness/population.py`, `harness/spatial_split.py`,
`harness/labels.py`, `experiments/exp058`, `exp060`, `exp060B`, `exp061`,
`exp070`, `metrics/{edges,partition,ranking}.py`. Retired packages
(`legacy/`, `cell_graph.py`, `assemble/`, `global_merge/`, `attic/`,
`experiments/pcfg/`) were out of scope.

**The direct answer to the question asked.** Every proximity number in the
program — EXP-058's union-find rungs, EXP-060's filter sweep, EXP-060B's object
panel, EXP-061's cone — is computed between **skeleton endpoints** (degree-1
nodes of the contracted L2 graph), via the same `build_candidate_panel` or the
same per-atom endpoint spans. There is no centroid-to-centroid metric anywhere
on the critical path, so there is no third metric to reconcile. EXP-070
(this session) introduced the object metric — every L2 node — and showed it is
strictly tighter (endpoints are a verified subset of nodes; 0 ordering
violations on 15,727 pairs) and moves reachability by 8–13 points without
changing the verdict. Coordinates are nm and isotropic in both tables (median
nearest-neighbour |dx|,|dy|,|dz| = 720/736/760 nm — no missed 8×8×40 voxel
scaling).

### Noted, not changed

- **Endpoint set differs by 154 endpoints between experiments.** EXP-060 and
  EXP-070 keep endpoints with a finite position; EXP-060B and EXP-061 also
  require a finite tangent (5,103,104 vs 5,102,950). 0.003%; it is the
  64.6%-vs-64.9% discrepancy EXP-070's evaluation already notes.
- **Span-5 tangent on short leaves** (suspicious, no wrong number): 1.79% of
  tips have a tangent obtuse to their own last edge, almost all on segments
  with <5 interior nodes, where the "tangent" is the chord to the junction of a
  hooked leaf. Correct as coded; whether it is the direction EXP-061 wants at a
  spine-like tip is a design question.
- **EXP-060B's median panel** excludes atoms with zero in-radius neighbours
  (`sizes` is built from atoms present in `nearest`). At 2/5 µm essentially
  every atom has neighbours; not counted.

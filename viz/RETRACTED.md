# ⚠️ RETRACTED — synthetic visualization data

`sample_connectome_viz.json` and any `.swc` exports derived from it were
produced by `scripts/export_viz_data.py` (now under `quarantine/scripts/`) from
**manufactured fragments, fabricated synapses, and injected frankenmerges** —
not from real MICrONS segmentation.

These files were described as community-validation exports. They are not valid
for that purpose and must not be redistributed. `connectome_visualizer.html`
renders whatever data it is given; the defect is entirely upstream.

See [`../docs/synthetic_data_audit_and_dataset_plan.md`](../docs/synthetic_data_audit_and_dataset_plan.md).
